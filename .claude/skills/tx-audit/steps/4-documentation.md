# Step 4: Documentation

This is the final step and it produces the deliverable, IN YOUR REPLY. Write no files, change no code, open no branch — the report is the output. Read the findings the earlier steps produced (they are in "Work so far" above) and compile them into one prioritized report: rank by impact and confidence, lead with the top three, and for each keep the evidence, the consequence, and the practical recommendation intact rather than paraphrasing them into vagueness. Say explicitly what a remediation run would have to do, so the user can start one without re-deriving any of this. If the earlier steps disagreed, say so rather than silently picking a side.

Finish with a short report for the next step: what you found or changed, files touched, checks run and their result, and a verdict line `VERDICT: done | blocked | needs-fix`.
