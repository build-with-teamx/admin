# Step 3: Performance

This is the performance pass of a READ-ONLY audit — do not edit anything. Measure where you can and read where you cannot, and be explicit about which is which. Report latency, throughput, resource use, and cost characteristics of the surface under audit, each finding with its evidence, consequence, priority, and a practical recommendation. You do not own a pass/fail verdict — report findings for the report.

Finish with a short report for the next step: what you found or changed, files touched, checks run and their result, and a verdict line `VERDICT: done | blocked | needs-fix`.
